Round 5 · session × mode × style

The accent is derived, not chosen. Gradient only in header + footer.

Two axes now drive the chrome. Session is what is loaded (moleculeType); Mode is which tab is open (activeTab). The accent is neither — it is resolveEnvAccent(activeTab, moleculeType), and the null check runs first: with no file loaded the accent is 'none' in both tabs, so the Database Hub does not go amber on an empty session. Everything still renders through exactly two elements — a .hf-env layer inside the dark nav and another inside the dark status bar, both clipped by overflow:hidden. The ruler/toolbar band, the white viewport canvas, both sequence tracks, the white Hub table card and the cream Hub backdrop carry no wash in any style.

THE FIVE REAL STATES — data-env is an output, never a choice: 1 · no file  + Viewport → none  neutral chrome, no accent
2 · no file  + Hub     → none  still no accent — null wins over the hub check
3 · nucleotide + Viewport → nucleotide  sky
4 · protein  + Viewport → protein  violet
5 · either   + Hub     → hub  amber, whichever molecule is loaded

LAYERED LIGHT

Draft fidelity — layout is schematic, and the protein content (residue strip, hydropathy, secondary structure) is an illustrative motif, not Rev7p's real sequence. In every style the gradient is confined to the two .hf-env layers inside the dark nav and status bar; the toolbar/ruler band, the white canvas, both sequence tracks, the white Hub table card and the cream Hub backdrop are flat in all nine. One open decision is baked into this file: nucleotide's --env3 is shown as #0d9488 (teal-600) instead of the existing #6366f1 (indigo), because indigo sits 15.6° from the protein anchor in OKLCH and makes nucleotide and protein chrome hard to tell apart. It is marked as a proposal in the CSS and is one line to revert. The frame stays dark-chrome-over-working-surface in both page themes — that pairing is the product.
