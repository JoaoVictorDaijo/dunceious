# Stored standard documents

Only documents whose terms allow redistribution are stored here. Everything else is pinned in
[`../sources.json`](../sources.json) and fetched with `npm run standards:fetch`.

## `embl-usrman-r143.txt`

ENA/EMBL flat file user manual, Release 143 (March 2020), EMBL-EBI, retrieved 2026-10-22 from
<https://ftp.ebi.ac.uk/pub/databases/embl/doc/usrman.txt>. Stored unmodified. The manual
permits copying and redistribution without advance permission provided its own permission
statement accompanies each copy; that statement is at the top of the file and must stay there.
