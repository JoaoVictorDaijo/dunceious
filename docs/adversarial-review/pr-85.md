### Won't-fix rationale (#7)

The reviewer proposed `margin-block: 2px`. Rejected: `.custom-scrollbar-pro` serves **both**
vertical and horizontal scrollers, and Blink applies only the along-axis margins per
orientation. `margin: 2px` is therefore correct for both; `margin-block` would go inert on the
horizontal bar. The inert cross-axis values are harmless.

### Closing the test blind spot

`src/app/__tests__/scrollbarStyles.test.ts` (4 cases) reads source rather than rendering, because
jsdom does not lay out scrollbars: every standard scrollbar property must sit inside the
`@supports` guard; no component style block may declare one; both halves of each selector live in
themes.css; and every `scrollbar-on-light` call site must also carry `custom-scrollbar-pro`.
**Mutation-verified** — reintroducing `scrollbar-width` outside the guard fails case 1; reverting passes.
