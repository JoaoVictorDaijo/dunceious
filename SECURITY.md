# Security policy

## Supported versions

Only the version deployed at [dunceious.pages.dev](https://dunceious.pages.dev/) (the latest release on `main`) receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/JoaoVictorDaijo/dunceious/security/advisories/new)). Do not open a public issue.

Include what is affected, how to reproduce it, and the impact you expect.

Dunceious has no backend: files are processed in the visitor's browser, and the only data sent elsewhere is the opt-in remote alignment to EMBL-EBI. Reports about that flow, about the static site, or about the build and its dependencies are all welcome.
